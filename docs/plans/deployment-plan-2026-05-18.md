| # | 任务 | 负责人 | 预估工时 | 前置依赖 |

| 2.5.2 | **DB Migration 执行** | 后端 | 0.5 天 | 无 |
| 2.5.3 | **JWT_SECRET 生产密钥配置** | DevOps | 0.5 天 | 无 |
| 2.5.4 | **NODE_ENV=production 验证** | 后端 | 0.5 天 | 2.5.2 |
| 2.5.5 | **端到端冒烟测试** | 测试 | 1 天 | 2.5.1, 2.5.2 |

### 交付物

- [ ] Embedding 模型选定（如 text-embedding-3-small）

- [ ] 冒烟测试脚本 + 测试报告（覆盖注册→登录→发帖→投票→修正案）

## ⚠️ 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|:----:|:----:|---------|
| Embedding 模型选型延误 | 中 | 高 | 默认选 text-embedding-3-small，支持运行时切换 |
| HTTPS 证书申请耗时 | 低 | 中 | 使用 Let's Encrypt 自动化 |
| 测试覆盖提升慢 | 中 | 中 | 优先 P0 核心路径，并行执行 |
| Qdrant 生产调优 | 中 | 低 | 当前 ILIKE 降级可用 |
